# 流式片段评分与家庭趋势设计

## 目标

将连续录音拆成接近 60 秒的本地 WAV 片段。切分优先使用本机 VAD
检测到的静音边界，避免截断一句话；每个完成片段立即进行本地转写、
声纹归属和大模型沟通评分。大模型为每条有文字的说话片段给出 -100 到
100 的分数和 Markdown 说明。家庭页按角色展示日、周、月、年评分曲线。

音频、VAD、ASR、声纹和角色纠正始终留在手机；只有片段的转写文本会按
顺序发送至用户自行配置的大模型。

## 录音与切段

录音入口改为 16 kHz 单声道 PCM 流。`RecordingSegmentCoordinator` 在内存
中维护未落盘的 PCM 滑动窗口，并持续运行本地 VAD：

1. 每个片段以 60 秒为目标长度。
2. 到达目标前，在最后 12 秒内记录最近的可切分静音边界；优先在该边界
   写出 WAV。
3. 未找到合适静音时，最多向后等待 6 秒；仍无边界时在 66 秒处强制收尾，
   保证长录音不会持续累积为超大文件。
4. 选定边界后的 PCM 会保留为下一个片段的开头，确保声音既不丢失也不
   重复。
5. 用户停止时，剩余有效语音立即写成最后一个片段；纯静音余量丢弃。

每个已落盘片段都会立即创建一个本地会话记录，并由独立的本地分析队列
按顺序执行 ASR、情绪和声纹识别。录音流继续运行，不等待分析或网络评分。
片段记录保留同一 `recordingGroupId`，对话页按连续录音归组显示，组内仍可
播放和删除任一片段。

## 片段评分与队列

`LocalUtterance` 新增持久化的 `LlmSegmentReview`：状态、尝试次数、更新时间、
下一次重试时间、-100 到 100 的分数、Markdown 说明和错误摘要。旧的会话级
复核数据保持可读，新的录音改用片段级复核。

全局 `LlmReviewQueue` 改为以 `(conversationId, utteranceId)` 为任务单位：

- 每次只发送一个可评分的说话片段，保持 3 秒最小请求间隔。
- 提示词要求只输出可解析 JSON：`score` 为整数且在 -100 到 100，`markdown`
  为手机友好的说明。解析失败视为失败并沿用 15 秒、1 分钟、5 分钟、20 分钟、
  1 小时、3 小时的持久化退避。
- 成功后写入对应说话片段；失败任务在应用重启后继续。
- 音频、声纹向量、角色档案和 API Key 不会进入请求。

## 交互与展示

对话列表只展示角色及其沟通得分，不再展示“积极、消极、中性”等本地情绪
标签。每个片段中有多个角色时，分别显示每个角色的已完成评分：

- 负分使用红色，例如 `妈妈 -72`。
- 正分使用绿色，例如 `爸爸 +48`。
- 0 分使用中性灰色 `0`，但不显示“中性”文字。
- 尚未评分显示简洁的“评分中”，不伪造数值。

对话详情逐句显示角色、转写、时间和分数，并保留 Markdown 复核卡片。片段
级分数不取代本机声学情绪结果；后者继续用于本地分析，但不在主列表占用标记。

家庭页为每个已命名角色显示独立的“沟通评分趋势”卡片，提供日、周、月、年
四个切换项：

- 日：最近 24 小时，按小时聚合。
- 周：最近 7 天，按天聚合。
- 月：最近 30 天，按天聚合。
- 年：最近 12 个月，按月聚合。

每个点是该角色在该时间桶内所有已完成片段评分的等权平均；卡片同时显示
已评分片段数。无数据时间桶显示断点而不是补 0 分，避免歪曲趋势。纵轴固定
为 -100 至 100，负区红色、正区绿色并带 0 基线。

## 失败处理与兼容

- 未配置 Key 时继续完成本地切段与分析，但不创建网络评分任务。
- VAD、文件写入或分析失败时，已安全写出的片段仍保留；错误片段可从对话页
  重新分析。
- 旧会话 JSON 缺少 `recordingGroupId` 或片段评分时按单片段会话读取，不丢失
  历史录音、声纹或旧复核结果。
- 删除一个片段只删除其对应本地音频、转写、评分与复核数据；按时间清理仍按
  片段创建时间执行。

## 验证

自动测试将覆盖：

1. VAD 边界选择、66 秒无静音兜底和尾段收尾。
2. PCM 分段连续性：无字节丢失或重复。
3. 单说话片段评分 JSON 的合法解析、非法分数重试、全局串行顺序和重启恢复。
4. 多角色片段的红绿分数聚合，以及日、周、月、年时间桶的平均和空桶处理。
5. 旧会话 JSON 兼容、逐片段删除与现有更新/录音/角色纠正回归。
6. Flutter 全量测试、静态检查，以及发布后 Android 签名 APK 与更新清单核验。
